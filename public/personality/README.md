# 人格视觉图片目录

将 16 张最终 AI 人格视觉图片放在本目录，并严格命名为：

`type01.webp` 至 `type16.webp`

建议统一使用 4:5 比例，至少 1200×1500 像素，WebP 单张尽量控制在 500KB 内。主体位置、光影、颗粒和构图密度应保持一致，只变化动物、天气、时间、材质与人格配色。

图片缺失时，结果页和分享卡会自动显示对应人格配色的艺术占位，不会报错。
